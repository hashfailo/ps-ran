## Model contract

The Bag-of-APIs model uses a 331-token API vocabulary, multinomial smoothed
class likelihoods, and an incremental per-event score. Training uses
deterministic sample-hash splits: 70% train, 15% validation, and 15% test.
The threshold is calibrated from validation benign final scores at the 99th
percentile. The test set is not used for fitting or threshold selection.

Saved artifacts include:

- `model.json`: model parameters, vocabulary, priors, threshold, metadata;
- `vocabulary.json`: ordered API vocabulary;
- `split_manifest.json`: sample-hash split membership;
- `training_summary.json`: fit and calibration summary.

## Known limitations

- The additional neural architectures are not trained in the current demo
  environment because PyTorch is not installed. Their code, preprocessing,
  checkpointing, calibration, Colab notebook, and FastAPI artifact loader are
  present; `/api/models` marks them unavailable until a complete artifact
  directory is copied under `models/`.
- Replay counts the report once before streaming so the UI can show progress.
- WebSocket sessions are process-local and intended for one local demonstrator.
- Event scores are model outputs, not calibrated causal probabilities of
  physical damage.
- The frontend displays only bounded argument names, not potentially huge raw
  argument payloads.
